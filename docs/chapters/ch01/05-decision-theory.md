# 1.5 决策论：从后验概率到最小贝叶斯风险

**原书定位**：Bishop (2006), PRML §1.5 *Decision Theory*。本文为独立原创教程。

## 目标与先修

区分概率估计和采取行动两件事；理解为什么 **MAP 只是在 0–1 损失下的特例**，如何处理不对称误判成本和拒绝决策。先修：条件概率、线性代数、概率期望。

## 1. 数学约定：损失的方向必须明确

给定已校准的后验 `p(C=c|x)`，将离散决策动作写为 `a∈{0,...,A−1}`，真实类别 `c∈{0,...,C−1}`。定义 `L[a,c]` 为选择动作 `a` 而实际类别是 `c` 的**损失**；因此矩阵的行是动作，列是真实类别，尺寸是 `A×C`。对一个样本的后验风险为

\[
R(a\mid x)=\sum_{c=0}^{C-1}L[a,c]p(C=c\mid x),
\qquad a^*(x)=\arg\min_a R(a\mid x).
\]

对批量 `N×C` 后验矩阵 `P` 和 `A×C` 损失矩阵 `L`，所有风险是 `R=P L^T`，维度 `N×A`。代码只接受行和为 1 的概率，并会对负数、NaN、错误形状报错，不对错误后验悄悄归一化。

## 2. 0–1 损失为什么得到 MAP

若动作是预测其中一个类别，并且 `L[a,c]=1[a≠c]`，则

\[
R(a\mid x)=1-p(C=a\mid x).
\]

最小化风险等价于最大化类别后验概率；所以 MAP 是 0–1 损失下的最优决策，**不是任意业务损失下的最优决策**。

## 3. 非对称损失：阈值不是 0.5

二分类 `c∈{0,1}`；假设将真实类别 1 误判为 0 的损失为 5，将真实类别 0 误判为 1 的损失为 1：

\[
L=\begin{bmatrix}0&5\\1&0\end{bmatrix},\qquad p=p(C=1\mid x).
\]

预测 0 的风险为 `5p`，预测 1 的风险为 `1−p`。因此**选择 1 当且仅当** `p>1/6`；在相等时按代码约定选择索引较小的动作。这是固定损失设定的结论，不意味着所有问题都应采用 1/6 阈值。

## 4. 拒绝选项

若增加一个统一代价为 `r` 的拒绝动作，二分类 0–1 损失下三种风险分别是 `p`、`1−p` 和 `r`。当 `r=0.2` 时，分类后验约在 `p∈(0.2,0.8)` 才选择拒绝；边界处依代码的最小索引 tie-breaking。拒绝不是“模型置信度真实度量”，前提是后验概率已适当校准。

## 5. 工程实现和验证

~~~python
from nano_prml.ch01.decision_theory import (
    zero_one_loss, reject_option_loss, expected_risk, minimum_risk_action
)

posterior = [0.7, 0.3]
print(minimum_risk_action(posterior, zero_one_loss(2)))  # 0
print(minimum_risk_action(posterior, [[0, 5], [1, 0]])) # 1
print(minimum_risk_action([0.5, 0.5], reject_option_loss(2, 0.2))) # 2
~~~

实验先从均匀分布中生成 `p(C=1|x)` 作为**已知真后验**，再按此概率生成独立标签 `Y`。比较使用同一测试样本时加权最小风险决策与 MAP 的真实损失、理论条件风险。它刻意**不训练概率模型**，因此不检验概率校准质量；不应称之为真实业务性能评估。

~~~bash
python -m nano_prml.ch01.theory_experiment --output artifacts/ch01/theory --seeds 0 1 2 --figures
~~~

会生成 `decision_cost.png`。**独立验证**有两条：手工推导 1/6 阈值；逐样本断言最小风险规则的理论条件成本不大于 MAP 的条件成本。有限样本真实损失存在波动，不应强求每次模拟的经验成本都严格更低。

4. 研究当提供给决策系统的后验不准确时，最优行动和代价如何变化；区分模型误差与决策规则误差。
