# AUTHORING：标准章节模板

每节必须按此顺序独立完成：

1. **目标、先修知识和原书定位**（以官方目录为准）。
2. **问题与直觉**：构建一个能清楚暴露模型假设的原创例子。
3. **数学符号与假设**：变量定义、shape、数据分布和适用边界。
4. **推导**：每步解释概率恒等式、代数变换和优化依据。
5. **透明实现**：先 NumPy 参考版；需要深度学习时引入 PyTorch；其他库只作独立对照。
6. **实验设计**：合成/真实数据来源、独立划分、种子、baseline、metric、数值误差。
7. **验证**：解析 oracle / 有限差分 / 不变性 / 小规模精确枚举等至少两类。
8. **失败案例**：错误输入、病态矩阵、错误假设或分布偏移。
9. **原创练习**：数学题、实现题、反例题；标明扩展内容。
10. **来源**：原始论文/书籍节号、勘误、数据许可与复现指令。

所有课程正文与图表原创；不是翻译 PRML 的逐段替代品。避免显式逆矩阵，优先 lstsq/solve/Cholesky/SVD。
