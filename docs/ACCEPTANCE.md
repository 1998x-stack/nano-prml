# ACCEPTANCE：研究级门禁

## 数学正确性
- 每一个核心公式写出假设、参数范围与向量/矩阵维度。
- 适用时组合使用：解析解 oracle、有限差分、精确枚举、概率不变性、与独立库的对照。**至少两类**不同独立证据。
- 报告矩阵病态、数据退化、预测外推等边界；绝不能为了“通过测试”随意放宽浮点误差。

## 实验可信度
- 使用 train/validation/test 隔离；任何模型选择仅用 train/validation，不能看 test 调参。
- 固定并记录生成器、随机种子、训练/测试样本数量、分布假设、评价指标与依赖版本。
- 使用多次 seed，避免凭一次漂亮曲线断言普遍规律。
- 结果可机器读取，标注实验设置、噪声及数值精度。

- Ridge 不对截距施加惩罚；penalty=0 与 OLS 预测一致。
- Bayesian degree=0 与 Gaussian 共轭解析解误差 < 1e-10。
- 后验协方差对称，函数值预测方差非负；带噪观测预测方差多出 beta^-1。
- 浮点有限差分与解析梯度一致；病态样本有有限输出或明确失败。
- 独立测试集，三个随机种子，记录 train/test MSE 和条件数。
- Python 3.10、3.12 的 `ruff check .`、`pytest` 与实验脚本在 GitHub Actions 中通过。

## Stage 01 / 1.4–1.6 增量验收
- `V_1=2`, `V_2=π`, `V_3=4π/3`，高维对数体积保持有限；球壳比率随维度增大，极窄 ε 不发生减法消去。
- 立方体独立点对的 `E||X-Y||²=d/6` 数值符合种子无关的解析恒等式；距离 CV 是实验观测，不宣传无条件定理。
- 后验风险遵守 `R=PL^T`，0–1 损失等价 MAP，假阴性成本 5 时决策阈值为 `p1>1/6`。
- 拒绝动作与 tie-breaking 可重现；负损失、未归一化后验与非法形状必须失败。
- 交叉熵恒等式 `H(P,Q)=H(P)+D_KL(P||Q)`；公平硬币、独立/相关联合表解析 oracle 对照。
- 不同支持集的 KL 和交叉熵是正无穷，不用任意 epsilon 平滑或掩盖概率错误。
